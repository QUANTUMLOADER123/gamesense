# Minecraft UI для Roblox

Библиотека в стиле софта для Minecraft: ряд одинаковых панелей, строки-опции с рамкой и «•••» справа,
и настройки, которые с анимацией выезжают прямо под опцией (место освобождается, соседние строки
уезжают вниз, при закрытии — обратно). Это только интерфейс: игровую логику пишите в `Callback`.

Пример: [`example_mine.lua`](example_mine.lua). Превью тем: [`minecraft_preview.html`](minecraft_preview.html).

## Загрузка

```lua
local Minecraft = loadstring(game:HttpGet("https://raw.githubusercontent.com/QUANTUMLOADER123/gamesense/arena/8d6efc34-gamesense/minecraft.lua"))()
```

В Roblox Studio положите `minecraft.lua` в ModuleScript `Minecraft` и подключите через
`local Minecraft = require(script.Parent.Minecraft)` (так же сделано в примере с фолбэком).

## Окно

Окно — это ряд панелей и поле поиска под ними. Названия вкладок стоят **над** панелями,
по центру каждой колонки — как подписи, а не как заголовок внутри окна. Заголовка нет,
фон прозрачный, перетаскивания нет: меню всегда стоит по центру экрана.

```lua
local window = Minecraft.new({
    Theme = 1,                      -- 1..6: Nebula, Cyber, Bloom, Ember, Mint, Gold
    Acrylic = "auto",               -- "auto" = стекло-блюр, если клиент умеет
                                    --          (графика >= 8), "on" / "off"
    ToggleKey = Enum.KeyCode.Insert,
    Stars = true,                   -- падающие звёзды на фоне (по умолчанию вкл.)
    StarCount = 14,                 -- сколько метеоров
    GlassTransparency = 0.22,       -- прозрачность панелей: 0 = плотно, 1 = прозрачно
                                    -- (поле поиска на 0.10 плотнее панелей)
    -- Parent = game:GetService("Players").LocalPlayer:WaitForChild("PlayerGui"),
})
```

Размеры: панель 236 × 536, строка 32px, зазор 5px, поле поиска 300 × 36, полоса подписей 34px,
скругления панель 18 / строка 10 / контрол 7 / мелкое 5 — всё в `Minecraft.Radius` и
`Minecraft.Metrics`, можно менять до создания окна. Внутри блока настроек: padding 9, зазор 7.

В Roblox нет UI-«backdrop blur», поэтому блюр даёт `BlurEffect` в `Lighting`
(`MinecraftUIBlur`): он размывает **весь экран** за меню, плавно появляется при открытии,
пропадает при `Insert` и удаляется в `window:Destroy()`. Управление: `window:SetBlur(24)` — сила,
`window:SetGlass(0.5)` — прозрачность панелей.

Панели полупрозрачные (`GlassTransparency`, по умолчанию 0.22) с вертикальным градиентом —
сквозь них видно мир. Обводок и бликов по кромке нет: библиотека не рисует ни одного `UIStroke`.

### Звёзды

За меню падает поле метеоров: у каждого яркая голова, тонкий хвост с прозрачностью от головы к
кончику и две отстающие точки-искры. Траектория — диагональ под 38°, скорость и задержка разные,
так что поле не пульсирует в такт. Всё на твинах, без `RunService` — стоимость плоская.
Выключить: `Stars = false`, количество: `StarCount = 14`.

**Колорпикер.** Поле насыщенности/яркости сделано как во всех нормальных библиотеках
(сверялись с Fluent): ровная градиентная подложка `rbxassetid://4155801252`, тонированная
текущим оттенком, а не мозаика из ячеек. Под ней остаётся сетка 20×13 точных цветов — она
служит запасным вариантом, если текстура не загрузилась (модерация ассетов, оффлайн), так что
поле никогда не становится белым или пустым. Курсор — тёмное кольцо с белым ядром, читается
и на белом, и на чёрном, и на насыщенном цвете.

Полоса оттенка — шесть плоских сегментов (мульти-ключевые `ColorSequence` на некоторых
клиентах давали красный/чёрный/красный). Ниже — **альфа-бар** на шахматке, 8 пресетов и
hex-поле с альфой (`#RRGGBBAA`, клик — копирование).

Цвет можно задавать вместе с прозрачностью:
`ColorPicker({DefaultAlpha = 0.5, AlphaFlag = "esp_alpha"})`, у строки есть `:GetAlpha()`,
`:SetAlpha(a)` и `Callback(color, alpha)`.

### Acrylic: настоящее стекло, как во Fluent

В Roblox нет `backdrop-filter`, но есть 3D-стекло. Подход взят из библиотеки
[Fluent](https://github.com/dawid-scripts/Fluent): перед камерой ставится плоский
`Part` с `Material = Enum.Material.Glass`, `Transparency = 0.98`, `Size = Vector3.new(1, 1, 0)`,
`Anchored`, `CanCollide = false`, `CastShadow = false`, `CanQuery = false` и `SpecialMesh`
(`Brick`, `Offset = Vector3(0, 0, -0.000001)`). Движок подхватывает сцену **за** этим стеклом и
размывает её — получается акриловая пластина ровно под панелями, а остальной экран остаётся резким.

Геометрия считается от экранного прямоугольника панели: два угла (`AbsolutePosition` /
`AbsoluteSize`) переводятся в мир через `Camera:ScreenPointToRay(x, y)` на расстоянии 0.001,
затем `CFrame.fromMatrix(center, XVector, YVector, ZVector)` и `Mesh.Scale = Vector3(width, height, 0)`.
Пересчёт идёт на `CFrame` / `ViewportSize` / `FieldOfView` камеры и на изменение положения/размера
панели, поэтому стекло «приклеено» к меню, пока игрок крутит камеру. Отдельные листы получают
панели, поле поиска и попап колорпикера.

```lua
Acrylic = "auto"   -- по умолчанию: включается, если QualityLevel >= 8
Acrylic = "on"     -- включить принудительно
Acrylic = "off"    -- не создавать 3D-парты вообще
window:SetAcrylic("off")   -- переключить на ходу
window.AcrylicSupported    -- умеет ли этот клиент стекло
```

Всё создание обёрнуто в `pcall`, при выключенной графике или в окружении без 3D-стекла меню просто
остаётся обычными полупрозрачными панелями — без ошибок. Стекло довольно дорогое по GPU,
поэтому `auto` его не форсирует.

### Блюр: только за панелями

Общего блюра на весь экран нет вообще. `BlurEffect` не создаётся ни при каких опциях, тёмной
подложки за меню тоже нет — игра остаётся резкой и яркой по краям. Размытие есть ровно за
тремя вещами, каждая со своим отдельным стеклянным листом:

* за каждой панелью (`tab.Acrylic`, прямоугольник **этой** панели, не всего ряда);
* за полем поиска (`window.SearchAcrylic`);
* за попапом колорпикера (`Popup.Acrylic`).

`BlurMode` и `SetBlur()` оставлены ради совместимости, но больше не включают глобальный блюр:
`SetBlur(n)` только чуть уплотняет стекло, чтобы изменение было заметно.

**Без обводок и линий.** В библиотеке нет ни одного `UIStroke`, нет линии под названием
раздела и нет полоски слева у включённых строк: границы задаются только контрастом фона.
Свет даёт настоящий glow — `ImageLabel` с радиальной текстурой `rbxasset://textures/glow.png`,
растянутый через `Slice`, а не стопка полупрозрачных фреймов.

**Кнопки.** `AddButton` — это нажатие: значение не защёлкивается, `Callback` вызывается на каждый
клик. Если передать `Settings`, у кнопки появляются «•••» и такой же анимированный блок настроек,
как у тогов. `AddAction` — то же самое, но центрированная акцентная CTA-кнопка.

Попап позиционируется от сваотча с учётом скейла и границ экрана, сам переворачивается вверх,
если снизу не хватает места, и анимируется при открытии.

**Скругления.** Одинаковый радиус у панели, у вьюпорта со скроллом (иначе `ScrollingFrame`
обрезал строки прямым углом и углы «торчали»), у слота строки (клип во время раскрытия настроек),
у самой строки и у блока настроек. Цвета строки меняет единственная функция `Row:RefreshVisual` —
ховер больше не перебивает состояние включённой опции и не подсвечивает рамку.

Чекбоксы в настройках рисуют галочку **пиксельным глифом** 11×8 (как иконки библиотеки):
короткое левое плечо, длинное правое, глиф отцентрован по своей рамке. Две повёрнутые
полоски давали «V» и уезжали от центра, поэтому от них отказались.

* `Insert` — показать/скрыть (плавное затухание);
* поле «Поиск» под панелями фильтрует все панели сразу, несовпавшие строки скрываются,
  открытые настройки закрываются;
* тема задаётся только при создании окна; при желании потом можно `window:SetTheme(3)`
  или `window:CycleTheme(-1)` — это меняет цвета уже созданного меню;
* `window:Toggle(false)`, `window:Destroy()`.

Панель добавляется так:

```lua
local combat = window:AddTab("Combat")
```

Каждая панель одного размера (236 × 536). Сколько вкладок — столько панелей в ряд; окно
расширяется с анимацией, панели встают на места по очереди (stagger), на маленьком экране меню
само уменьшает масштаб.

## Анимации и отступы

Вся анимация идёт через один набор кривых (`T` в начале файла), поэтому меню двигается «одной рукой»:

| Токен | Кривая | Где работает |
|-------|--------|--------------|
| `Layout` | Quint 0.34s | сдвиг/размер панелей, тело, поиск |
| `Expand` | Back 0.36s | раскрытие блока настроек |
| `Collapse` | Quint 0.24s | закрытие (без отскока) |
| `Pop` | Back 0.36s | галочка, попап пикера, появление окна |
| `PopSoft` | Quint 0.26s | «подъём» контролов настроек, кнопки, фильтр |
| `Hover` | Quint 0.18s | ховер строки, поиска, выпадающих списков |
| `Color` | Sine 0.26s | смена темы, затемнение |

Что именно анимируется:

* **появление окна** — fade `CanvasGroup` 1 → 0 и scale 0.96 → 1 (Back), плюс стекло acrylic
  «конденсируется» через 60 мс после меню;
* **вкладки** — новая колонка поднимается снизу (`-12 → 0`) с задержкой 35 мс на колонку;
* **раскрытие настроек** — плита выезжает из-под строки, контролы поднимаются по очереди
  (stagger, не больше 0.2с на весь список), при закрытии — быстрый сложенный уход;
* **строка** — фон/текст плавно (0.20с), при ховере сама плашка поднимается на 1px, `•••`
  становится ярче; клик — короткий «присед»; включённая строка и CTA-кнопка получают
  мягкий bloom (радиальная текстура, не слоистый ореол);
* **чекбокс** — глиф галочки выпрыгивает из 2×2 в полный размер по Back-кривой;
* **слайдер** — круглый ползунок едет вместе с заливкой, при перетаскивании растёт с 9 до 13px,
  рельс с 6 до 7px;
* **дропдаун** — шеврон-пиксель поворачивается на 180°, пункты подсвечиваются плашкой с fade;
* **поиск** — при фокусе иконка-лупа становится акцентной, подложка плотнее;
* **попап пикера** — всплывает из 0.94 размера с fade, при закрытии сжимается.

Отступы собраны в `Minecraft.Metrics`: `Inset 12` (внутренние поля панели), `RowGap 5`,
`BlockPadding 9` / `BlockGap 7` (блок настроек) — блоки больше не «на глаз», а по одной сетке.

## Строки

```lua
combat:AddToggle({Name = "Anti Bot", Flag = "anti_bot", Callback = function(on) print(on) end})

combat:AddToggle({
    Name = "Attack Aura",
    Flag = "attack_aura",
    Settings = function(s)                 -- есть настройки -> справа появляются "..." 
        s:Slider({Name = "Range", Min = 1, Max = 8, Step = 0.1, Default = 4, Suffix = " studs"})
        s:Dropdown({Name = "Target", Options = {"Players", "NPCs"}, Default = "Players"})
        s:Toggle({Name = "Through walls", Default = true})
        s:Input({Name = "Filter", Placeholder = "nickname"})
        s:Keybind({Name = "Hold key", Default = Enum.KeyCode.Q})
        s:ColorPicker({Name = "Color", Default = Color3.fromRGB(186, 152, 255)})
        s:Button({Name = "Apply", Callback = function() end})
        s:Label("Текст подсказки")
    end,
})

combat:AddSlider({Name = "CPS Limit", Min = 1, Max = 20, Default = 12})
combat:AddDropdown({Name = "Aspect Ratio", Options = {"Default", "4:3", "16:9"}, Default = "Default"})
combat:AddInput({Name = "Nickname", Placeholder = "type here"})
combat:AddKeybind({Name = "Panic", Default = Enum.KeyCode.Delete})
combat:AddColorPicker({Name = "Box color", Default = Color3.fromRGB(255, 80, 80)})
combat:AddButton({Name = "Reset", Callback = function() end})
combat:AddButton({                      -- кнопка С настройками
    Name = "Advanced",
    Callback = function() print("pressed") end,
    Settings = function(s)
        s:Slider({Name = "Amount", Min = 0, Max = 10, Default = 4})
        s:Toggle({Name = "Silent", Default = true})
    end,
})
combat:AddAction({Name = "Apply all", Callback = function() end})   -- акцентная CTA
combat:AddSection("World")                 -- заголовок раздела
combat:AddLabel("просто текст")
```

**Управление (как в референсе):**

* левый клик по строке — включить/выключить или нажать (у слайдера — потянуть по строке);
* правый клик по строке с настройками — открыть/закрыть блок настроек (снизу, с анимацией);

* включённая опция подсвечивается фоном в цвет темы и мягким glow (не рамкой — обводок нет).

`Settings` можно передать и таблицей функций: `Settings = {build1, build2}`.

## Темы

| # | Имя | Акцент |
|---|-----|--------|
| 1 | Nebula | индиго-фиолетовый |
| 2 | Cyber | циан |
| 3 | Bloom | маджента |
| 4 | Ember | коралловый |
| 5 | Mint | мятный |
| 6 | Gold | янтарный |

Тема задаётся в `Minecraft.new({Theme = ...})`. Названия окна больше нет — заголовок убран.

`Minecraft.Themes` — список тем, `Minecraft.Metrics` — размеры (можно менять до создания окна).

## Значения и конфиги

У строк есть `:Get()`, `:Set(value, silent)` (при `silent = true` callback не вызывается), а у toggle
ещё `:ToggleValue()`. Все значения дублируются в `window.Flags` по `Flag`.

```lua
local config = window:SaveConfig()   -- таблица: числа, строки, списки, цвета, тема
window:LoadConfig(config)            -- применяет и к флагам, и к контролам
window:GetFlag("attack_aura")
```
